## 0.0.1

- Initial public release of InTorrent.
- Android Flutter plugin backed by libtorrent v2.1.1.
- Added magnet link support.
- Added torrent status and progress reporting.
- Added torrent file listing.
- Added local HTTP streaming URLs with range-request support.
- Added contiguous byte availability checks.
- Added sequential stream prefetch controls.
- Added pause, resume, and torrent removal.
